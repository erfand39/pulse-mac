# یادداشت امنیت Pulse Mac

- renderer در sandbox با contextIsolation اجرا می‌شود. مسیر یا Origin دقیق frame، شکل و حدود ورودی IPC و مجوز مسیر انتخاب‌شده در Main بررسی می‌شوند. renderer مجوز Node ندارد و درخواست Permission هندلر رد می‌شود. CSP تولید اسکریپت inline و اتصال شبکهٔ renderer را می‌بندد. تصاویر HTTPS کاربردی مانند avatar و thumbnail مجازند. باز کردن مرورگر به دامنه‌های HTTPS لازم محدود است.
- ذخیرهٔ credential GitHub از Electron safeStorage و Keychain استفاده می‌کند. فقط وضعیت وجود credential به renderer برمی‌گردد. ورودی توکن هنگام تایپ در حافظهٔ فرم است و پس از ثبت حذف می‌شود. نشانی‌های HTTP و magnet هنگام ذخیرهٔ پروفایل روی مک با Keychain رمز می‌شوند. نام فایل و مسیر انتخاب‌شدهٔ cookies.txt دادهٔ عادی پروفایل‌اند. Authorization و Cookie در HTTP IPC پذیرفته نمی‌شوند. نشانی دانلود در نمای همان وظیفه قابل مشاهده و کپی است. Open With و مسیر ابزار با انتخاب بومی تأیید می‌شوند.
- redirect دانلود HTTP حداکثر پنج گام است. تغییر مبدا هدرهای غیرضروری را حذف می‌کند و downgrade از HTTPS مسدود است. TLS پیش‌فرض برقرار است. دریافت فایل متادیتای تورنت از HTTP سقف یک MiB دارد. tracker خارجی، web seed، LSD و آدرس همتای موجود در magnet نادیده گرفته می‌شوند. برنامه torrent tracker server راه‌اندازی نمی‌کند.
- نصب yt-dlp فقط برای `yt-dlp_macos` نسخهٔ `2026.10.26` از مخزن رسمی انجام می‌شود. hash دقیق با SHA2-256SUMS و asset digest همان انتشار تطبیق داده شده است. نصب پس از کنترل اندازه، SHA-256 و اجرای `--version` با rename اتمیک انجام می‌شود. FFmpeg جداگانه از فایل مورد اعتماد کاربر انتخاب می‌شود. فرمان‌ها با آرایهٔ آرگومان و بدون shell از طرف renderer اجرا می‌شوند.
- فورک شخصی از مسیر ساخت محلی یا artifact متعلق به همان فورک به‌روزرسانی می‌شود. endpoint دانلود و نصب آپدیت upstream از Main، preload و رابط حذف شد. برنامه از Windows installer یا payload renderer برای به‌روزرسانی استفاده نمی‌کند.
- برای build شخصی روی مک، `npm run dist:mac:arm64` امضای ad hoc خود برنامه را اعمال می‌کند. برای توزیع، از Developer ID و credential پشتیبانی‌شدهٔ electron-builder مانند `APPLE_API_KEY`، `APPLE_API_KEY_ID`، `APPLE_API_ISSUER` استفاده کنید و `PULSE_MAC_SIGN=1 npm run dist:mac:arm64` را اجرا کنید. حالت توزیع hardened runtime و سازوکار notarize/staple خود electron-builder را برای .app فعال می‌کند. با `codesign --verify --deep --strict` و `xcrun stapler validate` بررسی کنید. notarization مستقل DMG در صورت نیاز از notarytool و stapler روی مک انجام می‌شود. در اجرای فعلی Linux هیچ‌کدام از این مراحل Apple اجرا نشده‌اند.

## ممیزی وابستگی‌ها

`npm audit --json` در ۲۰۲۶-۱۱-۱۸ با exit code 1 ده مورد گزارش کرد. ۴ مورد High و ۶ مورد Moderate بودند.

- `ip@2.0.1`، `bittorrent-tracker@11.2.3`، `torrent-discovery@11.0.21` و `webtorrent@3.0.21` در زنجیرهٔ یک advisory مربوط به طبقه‌بندی IP هستند. کد import مستقیم آسیب‌دیده در parser سرور UDP وابستگی است. Pulse Mac tracker server ایجاد نمی‌کند و tracker کلاینت نیز غیرفعال است. نسخهٔ جایگزین پیشنهادی npm نسخهٔ بسیار قدیمی WebTorrent است و برای این بیلد نصب نشده است. [GHSA-2p57-rm9w-gvfp](https://github.com/advisories/GHSA-2p57-rm9w-gvfp)
- `minimatch@9.0.9,10.2.6`، `@electron/universal@2.0.3`، `app-builder-lib@26.18.0`، `electron-builder@26.18.0`، `dmg-builder@26.18.0` و `electron-builder-squirrel-windows@26.18.0` ابزارهای توسعه/بسته‌سازی‌اند. الگوهای glob از تنظیمات محلی ثابت پروژه می‌آیند. downgrade پیشنهادی npm به نسخهٔ عمدهٔ قبلی سازگاری بیلد را تغییر می‌دهد و اعمال نشده است. [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)
