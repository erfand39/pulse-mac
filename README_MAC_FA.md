# Pulse Mac

مدیر دانلود محلی برای مک‌های Apple Silicon، از جمله MacBook Air M1. نسخهٔ فورک `1.0.20-mac.1` بر پایهٔ Pulse Download Manager از TheGreatAzizi است. مجوز و انتساب در [LICENSE](LICENSE) و [NOTICE](NOTICE) آمده‌اند.

## نصب روی مک

برای ساخت از سورس به macOS 13 یا جدیدتر و Node.js `24.22.1` برای ARM64 نیاز است. حداقل macOS از فایل Info.plist توزیع رسمی Electron 45.3.1 به دست آمده است. اجرای بسته به Node.js جداگانه، Python، Homebrew یا سرویس شبکه‌ای جداگانه وابسته نیست.

```bash
uname -m
node -p 'process.arch'
npm ci
npm run typecheck
npm run lint
npm test
npm run dist:mac:arm64
bash scripts/verify-mac.sh
```

دو دستور اول در محیط ساخت M1 باید `arm64` نشان دهند. خروجی‌ها در این مسیرها ساخته می‌شوند.

- `dist/mac-arm64/Pulse Mac.app`
- `dist/Pulse-Mac-1.0.20-mac.1-arm64.dmg`
- `dist/Pulse-Mac-1.0.20-mac.1-arm64.zip`

پس از ساخت محلی، پوشهٔ برنامه را از DMG به Applications بکشید یا مستقیماً برنامهٔ ساخته‌شده را با `open "dist/mac-arm64/Pulse Mac.app"` باز کنید. DMG به‌صورت محلی با امضای ad hoc روی برنامه ساخته می‌شود. برای توزیع، بخش امضا در [یادداشت امنیت](docs/SECURITY_NOTES.md) را ببینید. دستورات معماری و یک نمونهٔ خروجی `file` در [گزارش آزمون](docs/MAC_TEST_REPORT.md) قرار دارند.

برای توسعه `npm run dev:mac` را اجرا کنید. Workflow [ساخت ARM64](.github/workflows/release.yml) همین مراحل را روی runner مک انجام می‌دهد. برای بازتولید بستهٔ آزمایشی لینوکس، `bash scripts/cross-app-linux.sh` فقط باندل ARM64 را می‌سازد.

## دانلود و تنظیمات

- با ⌘N پنجرهٔ افزودن دانلود باز می‌شود. لینک‌ها را می‌توان پیست یا روی پنجره رها کرد. در حالت گروهی هر لینک HTTP(S) را در یک خط وارد کنید. FTP پشتیبانی نمی‌شود.
- در گزینه‌های پیشرفتهٔ دانلود مستقیم می‌توانید SHA‑256 را وارد کنید. دانلود چندبخشی و ازسرگیری قطعه‌ها به Range معتبر و ETag قوی وابسته است. در صورت تغییر محتوا، فایل جدید با یک اتصال یا مجموعه‌ای از قطعه‌های تازه دریافت می‌شود.
- ⌘, تنظیمات است. از منوی برنامه یا آیکون نوار منو می‌توانید دانلودها را متوقف یا ادامه دهید. دکمهٔ قرمز به‌صورت پیش‌فرض پنجره را مخفی می‌کند و ⌘Q پس از توقف و ذخیرهٔ امن برنامه را می‌بندد. نمایش اعلان به تنظیمات Notification Center بستگی دارد. Login Item و رصد کلیپ‌بورد پیش‌فرض خاموش‌اند.
- پراکسی دانلود مستقیم را با `direct`، `system` یا نشانی HTTP، HTTPS و SOCKS5 بدون رمز عبور تنظیم کنید. مسیر دادهٔ BitTorrent مستقیم است. پراکسی سفارشی بعضی سرویس‌های ویدئو یا درخواست‌های GitHub را پوشش نمی‌دهد.
- برای ویدئو در تنظیمات ابزارها، `yt-dlp` رسمی مک را نصب کنید یا فایل اجرایی معتبر خود را انتخاب کنید. برای ادغام MP4، استخراج MP3/M4A و برخی حالت‌های زیرنویس و تصویر، نسخهٔ ARM64 ‏FFmpeg و FFprobe را کنار هم قرار دهید و FFmpeg را انتخاب کنید. اگر FFmpeg در دسترس نباشد، انتخاب‌های قابل دریافت به یک فایل موجود محدود می‌شوند. برای استخراج‌گرهایی که JavaScript لازم دارند برنامه Deno/Node موجود یا Node همراه Electron را بررسی می‌کند. مراجعه به Safari فقط با تأیید بومی فعال می‌شود. یک فایل `cookies.txt` انتخاب‌شده توسط شما نیز قابل استفاده است.
- برای فایل محلی `.torrent` از Open With، رها کردن فایل یا انتخاب‌گر استفاده کنید. در جزئیات وظیفه، فایل‌های موردنیاز را انتخاب کنید. شبکهٔ DHT عمومی پشتیبانی می‌شود. تورنت متکی به tracker خصوصی، web seed یا همتای شبکهٔ محلی پشتیبانی نمی‌شود. فایل‌های تورنت یا ویدئو را می‌توانید از Finder مدیریت کنید.
- جست‌وجوی GitHub بدون توکن کار می‌کند. توکن اختیاری را می‌توان در بخش ابزارها ثبت یا حذف کرد. قفل بودن Keychain ممکن است دسترسی به درخواست‌های احرازشده و لینک‌های ذخیره‌شده را متوقف کند. برای بازیابی لینک‌ها، پس از باز کردن Keychain برنامه را دوباره باز کنید.

## بازیابی و بکاپ

پروفایل جدید در `~/Library/Application Support/pulse-mac` است. برای بکاپ پس از خروج برنامه، این پوشه و پوشه‌های دانلود را کپی کنید. فایل‌های مخفی `.pulse-mac-<id>` کنار مقصد HTTP، به‌همراه `checkpoint.json` و فایل‌های `.part` برای ادامه لازم‌اند. پاک‌کردن دستی آنها بازیابی همان دانلود را از بین می‌برد.

حالت قبلی از `~/Library/Application Support/pulse-download-manager/pulse-state.json` یک‌بار کپی می‌شود و همان فایل قبلی باقی می‌ماند. اگر پروفایل قدیمی توکن متنی داشت، نسخهٔ جدید توکن را با Keychain محافظت می‌کند. کپی قدیمی همچنان ممکن است توکن متنی داشته باشد، پس دسترسی به آن را محدود کنید و در صورت لزوم توکن قدیمی را در GitHub تعویض کنید. فایل‌های نیمه‌تمام قدیمی حفظ می‌شوند. دانلود HTTP قدیمی که checkpoint معتبر Pulse Mac ندارد یک انتقال تازه را آغاز می‌کند.

در صورت خرابی `pulse-state-v2.json` برنامه از `.bak` معتبر استفاده می‌کند و یک نسخهٔ `.corrupt-*` نگه می‌دارد. اگر هر دو خراب‌اند، برنامه با پیام خطا متوقف می‌شود. پس از خروج، کل پروفایل را کپی کنید. فقط با وجود یک snapshot سالم، فایل اصلی را از همان کپی سالم بازگردانید. برای حجم پر، جدا شدن حافظهٔ خارجی یا خطای دسترسی، مقصد اصلی را دوباره وصل کنید یا فضای لازم را خالی کنید و Retry بزنید.
